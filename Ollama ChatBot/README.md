# 🦙 Ollama Chatbot

A simple chatbot built using **Python and Ollama** to interact with a locally running Large Language Model (LLM).

## ✨ Features

* 💬 Interactive chatbot
* 🦙 Uses Ollama for local LLM interaction
* 🧠 Maintains conversation through chat messages
* 🐍 Built with Python
* 🔒 Runs the model locally

## 🛠️ Technologies

* 🐍 Python
* 🦙 Ollama
* 🧠 LLM

## ⚙️ Setup

Install the Ollama Python library:

```bash
pip install ollama
```

Make sure Ollama is installed and running on your system, then download a model, for example:

```bash
ollama pull llama3.2
```

## ▶️ Run

Run the Python chatbot:

```bash
python app.py
```
